# v1.0.0 - Initial Release

**Released**: April 8, 2026

## Overview

First stable release of the Obsidian Vault Datasource library - a Dart package for working with Obsidian vaults using functional programming with fpdart.

## Features

### Core
- ✅ Create new vaults from scratch
- ✅ Load existing vaults from disk
- ✅ Refresh vault state from filesystem
- ✅ CRUD operations for notes and folders

### Notes
- ✅ Create, read, update, delete notes
- ✅ Wiki-style links `[[link]]` support
- ✅ Frontmatter properties (YAML)
- ✅ Title extraction from content or filename

### Folders
- ✅ Create folders
- ✅ Nested folder hierarchy
- ✅ Notes in subfolders

### Links
- ✅ Parse wiki links from Markdown
- ✅ Create links programmatically
- ✅ Alias support `[[target|alias]]`

### Search
- ✅ Search by title
- ✅ Search by content

## Architecture

- Clean Architecture (Domain, Data, Core, API)
- fpdart for functional error handling (TaskEither)
- Equatable for value equality

## Package Structure

```
lib/
├── src/
│   ├── domain/          # Entities, failures
│   ├── data/            # Repositories, adapters
│   ├── core/            # Use cases
│   └── api/             # Public API
```

## Dependencies

- `fpdart: ^1.2.0` - TaskEither for async error handling
- `equatable: ^2.0.7` - Value equality
- `yaml: ^3.1.2` - Frontmatter parsing

## Migration Notes

This is the initial release - no migration needed.
